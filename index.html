UNOFFICIAL COMMUNITY MIRROR

An easier way to try PdfCraft

This site simply makes PdfCraft easier to try without installing it. PdfCraft is developed by the ArtCraft Team and contributors. This mirror is not operated or endorsed by them.

You are loading the official v0.4.0 WebAssembly module with a community bootstrap. The web and desktop apps share an editing engine, but their features are not identical.

  • PDFs open through the browser picker; saving downloads a new file without overwriting the original. Some image insertion/replacement, attachment downloads and data imports are not wired up on the web.
  • Some preferences can persist, but desktop document crash recovery is not wired up. Download saves explicitly; do not rely on reloading to restore documents.
  • WebGL2 is required. Large PDFs and heavy operations depend on browser memory. OCR text recognition is currently unavailable in this mirror.
  • Browser restrictions do not imply the same restrictions on desktop. PdfCraft itself is still alpha; the desktop app is not guaranteed to have every feature complete.

Based on the v0.4.0 source, not an exhaustive test of every editing feature. Keep backups and evaluate the official desktop app before production work.
